# 1. 数据查询
目前收录了～2000个AIMD构建的晶体/非晶/液态模型，涵盖不同密度，温度，淬火速率得到的多个独立构型。可以根据元素组合（e.g., Ge-Te），根据化学式（e.g., Ge0.5Se0.5）查询结构，查看该结构相关的meta data，并进行简单的可视化。

# 2. 数据筛选
设置了多个筛选条件，例如相，功能（PCM/OTS/SOM），温度，数据贡献者。

# 3. 数据分布可视化
使用SOAP对材料结构进行特征化，再使用PCA对高维结构特征进行降维可视化，用于直观查看结构多样性分布，并且可以交互式地查看任意分布中的对应结构。

# 4. 用于机器学习的训练集数据
本数据库还包含了多个DFT单点能计算标注的高精度数据集，可适用于机器学习势函数训练等后续应用。
